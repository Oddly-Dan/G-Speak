# G-Speak — Emoji-Speak Reference

Every emoji/word pair currently in the Emoji-Speak category (`js/app.js`,
`NAV_BLOCKS` → `id: "emoji"`), for use as a language-learning aid alongside
the app — e.g. printed via Settings → Print, or as a planning sheet.

The **Word** column is the label G-Speak already speaks aloud for that
emoji — nothing here is invented for this document. The **Translation**
column is left blank for you to fill in by hand (a second language, a
regional term, sign-language gloss, whatever's useful).

## Extended Vocabulary

Not shown on the board itself, but findable by search once you're in
Emoji-Speak (and promotable onto the board by press-and-hold). Deliberately
limited to long-established, single-codepoint emoji that render reliably
across devices and OSes — skipping skin-tone variants, gender/profession
combinations, family groups, and flags, which are multi-codepoint sequences
that don't render consistently everywhere.
